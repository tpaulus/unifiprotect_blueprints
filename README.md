# UniFi Protect Home Assistant Blueprints

Import a blueprint into Home Assistant with the link beside it. Each blueprint can
then be configured as an automation in your instance.

## Blueprints

### Doorbell Ring Notifications

Get a mobile notification when someone rings your UniFi Protect doorbell. The
notification can include a snapshot and optional video clip, and can offer actions
to unlock a door or open a gate, play a TTS response, silence future alerts, or open
a Home Assistant dashboard view.

[![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fraw.githubusercontent.com%2Ftpaulus%2Funifiprotect_blueprints%2Fmain%2Fblueprints%2Fautomation%2Funifiprotect%2Fnotification_ring_event.yaml)

### Motion and Smart Detection Notifications

Get a mobile notification when a selected UniFi Protect sensor detects motion or
another smart event, such as a person or vehicle. Alerts can include a snapshot
and a video clip, and support presence filtering, a notification cooldown, and a
quick link to a dashboard view.

[![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fraw.githubusercontent.com%2Ftpaulus%2Funifiprotect_blueprints%2Fmain%2Fblueprints%2Fautomation%2Funifiprotect%2Fnotification_smart_motion_event.yaml)

### License Plate Notifications

Get a mobile notification when a UniFi Protect AI camera detects a license plate.
The alert includes the detected plate and a snapshot, with optional presence
filtering, cooldown and silence controls, and a link to a dashboard view.

[![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fraw.githubusercontent.com%2Ftpaulus%2Funifiprotect_blueprints%2Fmain%2Fblueprints%2Fautomation%2Funifiprotect%2Fnotification_smart_licenseplate_event.yaml)
